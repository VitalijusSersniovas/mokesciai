# Mano mokesčių euras

2025 m. mokesčių ir įmokų skaičiuoklė, parengta iš 32-osios svetainės versijos. Skaičiavimas vykdomas naršyklėje.

## Publikavimas

Saugykla `VitalijusSersniovas/mokesciai`, publikavimo šaka `main`. „GitHub Pages“ skiltyje „Deploy from a branch“ pasirinkti `main` ir `/docs`. Numatytas adresas `https://vitalijussersniovas.github.io/mokesciai/`.

Paleisti testus iš saugyklos katalogo komanda `node --test`. Vėlesnius pakeitimus skelbti į `main` po patikros. Ankstesnę publikaciją galima atkurti grąžinus patikrintą saugyklos versiją.

## Lankomumo statistika

„Cloudflare Web Analytics“ pridėti svetainės vardą `vitalijussersniovas.github.io`. Tos svetainės „Cloudflare“ pateiktą kodą įdėti į `docs/index.html` prieš `</body>`. Skaičiuoklės atlyginimo ir pirkinių įvestys analitikai neperduodamos. Patikrinti, ar peržiūra pasirodo „Cloudflare“ statistikoje.

- [„GitHub Pages“ publikavimo nustatymai](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [„Cloudflare Web Analytics“ prijungimas](https://developers.cloudflare.com/web-analytics/get-started/)
